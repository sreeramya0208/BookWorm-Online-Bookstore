# BookWorm --- Online Bookstore

BookWorm is a multi-page front-end online bookstore built with **HTML,
CSS, and JavaScript**. It demonstrates a simple shopping flow, from
browsing books to viewing an order confirmation.

## Features

-   Home page with featured books and a book-search option
-   Book catalogue with search functionality
-   Registration, login, and profile forms with basic input checks
-   Shopping cart with quantity increase/decrease and item removal
-   Subtotal and total calculation
-   Demo payment form with basic input validation
-   Order confirmation page
-   `localStorage` to retain cart and order information across pages

## Technologies Used

-   HTML
-   CSS
-   JavaScript
-   Browser `localStorage`

## Project Files

-   `index_1.html` --- Home page
-   `catalog.html` --- Book catalogue
-   `registration.html` --- Registration form
-   `login.html` --- Login form
-   `profile.html` --- Profile form
-   `cart.html` --- Shopping cart
-   `payment.html` --- Demo payment form
-   `confirmation.html` --- Order confirmation
-   `style_1.css` --- Stylesheet
-   `script.js` --- Page interactions and application logic

The catalogue refers to six optional book-cover image files: `book1.jpg`
through `book6.jpg`. Keep these in the same folder as the HTML files if
available.

## How to Run

1.  Download or clone this repository.
2.  Keep the HTML, CSS, JavaScript, and available image files together
    in the same folder.
3.  Open `index_1.html` in a web browser.
4.  Use the navigation links to browse the catalogue, add books to the
    cart, and try the demo checkout flow.

No installation or build step is required.

## Important Notes

This is a front-end learning project. Registration and login display
basic validation and success messages; they do not use a real user
account system or backend. The payment page is a demonstration only and
does **not** process real payments. Do not enter real card details.

Cart and order information are stored in the browser's `localStorage`,
so the data is specific to that browser.
